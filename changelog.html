更新日誌

3.2 Build 21

診斷回報

  • iPhone、iPad 與 Mac 版會在 App 發生崩潰或資料庫啟動失敗時，自動回報診斷資訊，協助定位問題。
  • 回報內容不會連結帳號身分或用於追蹤，也不會附上查詞文字、字典內容、收藏或歷史記錄。
  • App 隱私權說明已更新：蒐集崩潰、效能與其他診斷資料，僅用於 App 功能。

3.1 Build 20

  • 設定新增「Dictionary Visibility」頁面，可逐本決定哪些字典出現在查詞頁的字典選單。iPhone 與 iPad 位於設定的「Library」區塊，Mac 位於設定的「Dictionary Menu」面板。
  • 至少保留一本可見字典，最後一本可見字典的開關會停用；新加入的字典預設顯示。
  • 隱藏只影響選單選項，不會切換目前字典，也不會中斷進行中的查詞；已隱藏的字典仍可由收藏開啟查詞。
  • 這項設定只儲存在本機。

  • 至少保留一本可見字典，最後一本的開關會停用；新加入的字典預設顯示。
  • 隱藏只影響選單選項，不會切換目前字典，也不會中斷進行中的查詞；從收藏開啟隱藏字典仍可正常查詞。
  • 這項設定只儲存在本機。

  • iPhone、iPad 可從設定的「圖書館」進入，Mac 則位於設定的「Dictionary Menu」面板。

3.0 Build 17

新功能與介面

  • iPhone 與 iPad 改用系統原生搜尋列查詞：iPhone 在底部工具列提供搜尋按鈕，展開搜尋時保留字典內容，打字貓動畫同步回歸
  • 全新 Pro 會員頁面：以插圖介紹字典、收藏、iCloud 同步與智慧增益四大功能，顯示在地化價格，集中購買、恢復購買與會員狀態；從需要 Pro 的功能進入會直接顯示對應說明
  • 查詢起始、查無結果與空白字典庫換上專屬插圖空狀態，支援淺色與深色外觀
  • macOS 字典檔管理與增益規則改為獨立視窗，重複開啟時帶出現有視窗
  • 「關於」頁面重新編排版本資訊，並更新官方網站、支援、隱私與 Telegram 連結
  • 網頁主題精簡為預設、Gruvbox 與 Tokyo Night，並標示目前使用中的主題
  • 單字詳情捲動時加入柔和邊緣效果

修正與改善

  • 快速連續查詞時，舊查詢結果不再覆蓋較新的查詢
  • 資料庫無法開啟時顯示可重試的失敗畫面，不再直接閃退或重置原有資料
  • 尚未就緒（例如仍需下載）的字典檔不再被讀取，避免載入錯誤
  • 修正部分大型字典（如 Cambridge Dictionary）查詢特定單字時出現「Invalid record range」錯誤的問題
  • 查詞快取移至背景處理，減少介面卡頓
  • 編輯增益規則時保護未儲存的草稿，重設預設規則前先確認，失敗時顯示錯誤
  • 字典選擇按鈕加入輔助使用標籤與提示

3.0 Build 13

改進

  • iOS 採用系統原生搜尋介面：查詢欄整合至工具列，iPhone 上搜尋欄位於底部工具列，操作更貼近系統體驗
  • macOS 的「檔案配置指南」與「增補規則」改以獨立視窗開啟，可與設定視窗並排查看；未升級 Pro 時點擊「Upgrade to Pro」會直接帶你前往會員設定頁
  • 辭典庫掃描時只讀取已就緒的辭典檔案，尚未從 iCloud 下載完成的辭典不再於掃描時開啟，下載完成前以檔名顯示
  • 查詢與建議快取改於背景處理，輸入查詢與瀏覽辭典列表更加流暢
  • 專案升級至 Xcode 27，並移除 visionOS 與 Mac Catalyst 支援，專注於 iOS、iPadOS 與 macOS
  • iOS 查詢改用系統原生搜尋欄：iPhone 於底部搜尋列、iPad 於工具列啟動搜尋，字詞內容捲動時呈現柔和邊緣效果；打字貓動畫在原生搜尋中恢復顯示，查詢建議也會依可用空間自動切換水平或垂直排列。
  • 新增插畫空狀態：查詢起始畫面、查無結果與辭典庫空清單改以插畫呈現，介面更清楚友善。
  • Pro 購買頁面全新設計：以四張插畫介紹 Pro 重點（辭典、收藏、iCloud、Intelligence），價格資訊在地化顯示，並提供依情境安排的升級入口與統一的 StoreKit 購買列；macOS 設定中的會員頁改為直向內容，說明文字可捲動以支援較大的輔助使用字級。
  • 設定更安全、更清楚：離開有未儲存變更的規則編輯器時會先詢問儲存、捨棄或繼續編輯；重設預設規則前需再次確認，失敗時會顯示錯誤訊息；macOS 的辭典檔案管理移至獨立視窗；網頁主題選擇簡化，並在清單外標示目前使用的主題。

修正

  • 修正快速連續查詢時，先前查詢的結果可能覆蓋最新結果的問題；查詢結果與建議現在只對應當前的請求
  • 修正切換辭典來源（本機／iCloud）時，舊的快取列表可能覆寫最新掃描結果的問題
  • 修正辭典資料庫啟動失敗時 App 會直接結束的問題：現在會顯示錯誤說明與「重試」按鈕，且資料不會被重置或取代
  • 修正上次查詢結果快取可能被較舊的寫入覆蓋的問題，重新啟動後能正確還原最近的查詢
  • 穩定性改進：資料庫啟動失敗時可於應用程式內重試，不再無法進入；查詢結果依請求隔離，較舊的回應不會覆蓋較新的查詢；查詢快取移出主要執行緒以減少卡頓，並確保最後一次查詢快照正確還原。
